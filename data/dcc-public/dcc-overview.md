# Digital Culture Center (DCC) Miami

Digital Culture Center is a Miami cultural infrastructure pilot. It publishes
workshops, an Open Lab, partner pathways, and a governed Institutional Memory
agent for public and staff questions.

DCC is not a chatbot vendor. The public surfaces answer from approved records
and pause before any outreach or operational write.

Canonical public routes on the live Infra24 deployment:

- `/applied-ai` — recruiter-facing demo hub
- `/memory-agent` — redirects to the DCC Memory Agent
- `/o/dcc/memory-agent` — canonical Memory Agent UI

The Network Readiness agent stays behind an admin flag until enabled.
