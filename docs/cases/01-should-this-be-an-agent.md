# Should this be an agent?

**Prompt:** A cultural lab wants "an AI" to launch its Saturday program each cycle.

**Cut the work**

- Retrieval of the handbook is enough for "what is the Saturday window?"
- A spreadsheet already totals the budget.
- The only new failure mode is a plan that forgets a blocked instructor or invents a grant.

**HITL boundary:** any task list, email, purchase, or second venue.

**Kill criteria:** if the brief is always the same six fields, ship a form. Keep the agent only if the brief changes and citations must travel with the packet.

**This repo's answer:** retrieve + calendar + budget, then pause. That is an agent with tools, not a chatbot, and not autonomy.
