# Discovery — Creative Institution Program Launch

**Customer shape:** a small cultural lab that already runs Saturday sessions and needs a repeatable launch packet, not a chatbot.

**What is broken:** staff write the same schedule, equipment, and budget notes by hand each cycle. The risk is not "we need AI." The risk is a plan that forgets a blocked Saturday or a cap.

**Who decides:** a program lead approves the packet. A technician owns equipment. Instructors do not want mail sent on their behalf.

**Systems in the room:** shared calendar, a budget spreadsheet, a markdown handbook. No ServiceNow. No CRM export.

**Why an agent at all:** one brief should retrieve the handbook, check calendar and budget, and pause before filing tasks. If those three reads are enough, a checklist would have been the smaller system — the agent is justified only because the brief changes and the sources must be cited.

**Stakeholder map**

| Role | Cares about | Can block |
| --- | --- | --- |
| Program lead | Scope, budget cap, public language | Approval |
| Technician | Equipment leaving the cage | Saturday coverage |
| Instructor | Calendar, no surprise email | Week 3 absence |
| Requester / artist | Clear intake, no invented KPIs | Trust |
